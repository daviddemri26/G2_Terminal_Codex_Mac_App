# G2 Bridge Guide — Privacy notice

Draft for companion version 0.1.0. Prepared 21 September 2026.
Publish the reviewed notice at a stable public URL before store submission.

G2 Bridge Guide is a setup and reference companion. Its guide content is included
in the application package. The guide's own code does not create an account,
request your microphone, fetch your conversations, connect to your Mac, or ask
for a pairing token. It does not include analytics, advertising, or a backend
operated for this companion, and does not persist navigation history.

The companion uses the Even Hub SDK to display its reference pages and receive
navigation events. Even Realities operates the phone application and platform;
their own privacy terms govern that host software.

Reference links identify the public setup tutorial hosted on GitHub Pages,
documentation, and GitHub support issues. If you choose to visit these sites,
their operators receive the normal information associated with your visit and
apply their own privacy policies. There is no automatic external fetch by the
guide. A link does not send a Mac pairing credential or conversation content.

The separately installed G2 Bridge Mac software has a different role: it connects
Even Terminal to the Codex Mac app and maintains local configuration and delivery
records. This guide does not change OpenAI's, Even Realities', GitHub's, or
Tailscale's handling of their own services. See the
[G2 Bridge documentation](https://daviddemri26.github.io/G2_Terminal_Codex_Mac_App/)
before installing that separate software.

For questions about this companion, use
[the project's GitHub issues](https://github.com/daviddemri26/G2_Terminal_Codex_Mac_App/issues).
Do not post private conversation content or pairing credentials in public issues.
If you submit information to GitHub yourself, that information is governed by
GitHub's policies. The companion itself has no saved user data to delete.
