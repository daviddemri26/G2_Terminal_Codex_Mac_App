# Review notes — Even Terminal for Codex Mac App Guide 0.1.1

## What to review

This package is a small English reference guide. It provides a useful setup and
troubleshooting reference on G2, with more detailed explanations and URLs in the
phone view. It does not submit AI prompts or provide the terminal interface.
The existing Even Terminal product provides that interface; a separately
installed Mac bridge connects it to the Codex Mac App.

Beyond the normal Even Hub environment, guide review requires **no additional
account, external service, Mac, or pairing secret**.
External installation is needed only to use the separate bridge described by it.
Those requirements are stated in the listing and the guide.

## Review flow

1. Launch the guide. Confirm the four entries: Set up, Daily use, Troubleshoot,
   and About.
2. Select each entry. Read the short reference page, then double-tap to return
   to the menu.
3. Double-tap on the menu. Confirm that the platform's exit confirmation appears;
   cancelling it should leave the guide usable.
4. Read the phone view. Check that guide links have readable URL alternatives.
   Automatic launch of a browser or Even Terminal is not promised.
5. On physical hardware, repeat navigation with the phone locked, then test
   unlock/resume and leaving/reopening the guide.

The guide needs no microphone or network permission. It displays no simulated
Mac status or invented connection success. Its menu/reference content should
continue to work when the separate Mac bridge is unavailable.

## Release notes for the first candidate

Initial English setup and reference guide for Even Terminal for Codex Mac App. Includes setup steps,
daily-use reminders, troubleshooting, compatibility guidance, and links to the
Mac installation tutorial and project support.
