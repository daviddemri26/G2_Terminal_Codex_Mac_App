New here? Follow the five steps in order. Already set up? Jump to the part you need.

STEP 01

Check your starting point.

You need your Mac app, your glasses, and a connection between your Mac and phone. The installer checks the software before it makes changes.

✓

A Mac with Codex

macOS 14 or later. Apple Silicon is the reviewed setup. You already use Codex and are signed in.

✓

The reviewed Mac app version

26.915.31945 · build 9922, with the supported Codex.app or ChatGPT.app identity. Check the app's About window.

✓

Even G2, phone app, and R1

Pair your G2 glasses and R1 ring through the Even Realities app. Terminal Mode is the phone/glasses interface.

About compatibility

This community integration uses a private Mac app connection. A newer Mac app build needs review before it works. An exact minimum G2 firmware or phone-app version has not been certified. Check the compatibility record.

STEP 02

Give your devices a private connection.

For a first setup, use Tailscale on your Mac and phone. It lets your phone reach the Mac even when they are on different networks.

  1. Install Tailscale on both devices using the official guides below.
  2. Sign in to the same private Tailscale network on both.
  3. Turn the connection on, and complete the normal VPN/network-extension permission prompts.
Set up your Mac ↗Official Tailscale guideSet up your iPhone ↗Using Android? See below

Also available: Android instructions and Tailscale's first-connection walkthrough. No exit node or router port forwarding is needed for this setup.

Already using the same Wi-Fi or another connection?

Even Terminal already supports LAN and other modes. The local Codex adapter does not inherently require Tailscale. The installer can preserve an existing valid Codex LAN or named-interface profile, including its pairing credential. These existing profiles do not require Tailscale.

Tailscale is the physically reviewed setup here. Other modes have not been tested with this project's phone/glasses flow, and the app cannot independently verify their reachability. Existing public-tunnel profiles need advanced review and are refused by guided setup/QR generation. This release does not add a network-mode switch.

If a LAN/interface address changes, finish the current interaction, use Restart in G2 Bridge when it is safe and available, then show and scan the new pairing QR. Refreshing the QR alone does not reconnect the running bridge to the changed address.

Read what works underneath and what remains unverified.

STEP 03

Install once. Open from Applications.

The current installer builds the app on your Mac. First, it needs Apple's Command Line Tools with Swift 6 or later and Python 3. If you do not have them, open the Mac's Terminal app and run:

xcode-select --install

Finish Apple's installation dialog before continuing. This one-time Mac setup does not install or start Codex CLI.

  1. Download the G2 Bridge source ZIP.
  2. Expand the ZIP. Keep the extracted folder together.
  3. Double-click Install G2 Bridge.command inside it and follow the checks in its window.
  4. When it finishes, open G2 Bridge from Applications.
Download source installer ↗

The installer obtains the pinned Node runtime if needed, restores locked dependencies, runs offline checks, and builds the app. It creates a private pairing credential and a default project folder for a first setup.

What to expect from this public alpha

This is a source installer, not an Apple-notarized binary download. It needs internet access for dependencies and Apple's developer tools to compile locally. If macOS blocks it because the developer is unverified, check that it came from this repository. After the blocked attempt, go to System Settings → Privacy & Security → Open Anyway for that file, then confirm Open if you trust it. Follow Apple's instructions; do not override malware or damaged-file warnings or disable system-wide security.

The standard app location is /Applications. If it is not writable, a per-user ~/Applications option is explained. The service and credentials remain private to your user either way.

An existing managed bridge is not silently replaced by this first-install flow. Follow the reviewed update procedure.

STEP 04

Point your phone at the QR code.

  1. In G2 Bridge, open Connect and show the pairing QR code.
  2. On your phone, open the Even Realities app.
  3. Enable Terminal Mode in Settings and scan your bridge's QR code.

You do not need to type a token or address. The QR belongs to your own installation; keep it out of screenshots you share publicly.

Follow Even's phone, glasses, and ring instructions ↗
Use the host you just installed.

The official Terminal page also describes its generic host commands. G2 Bridge supplies your Mac host, so you do not need to start another Even Terminal host or a separate Codex engine.

STEP 05

Find a conversation you recognize.

Keep the Mac logged in and awake, with Codex and the configured network available. Check the G2 Bridge overview, then select a known Codex conversation in Even Terminal.

  1. Confirm that its title and history are the ones you expect.
  2. Send a harmless message in a conversation you intentionally choose for testing.
  3. Check that the reply appears both there on the Mac and on your glasses.

Now you have checked your actual devices. A green local status or successful installation tests alone cannot confirm what the glasses display.

From now on

Leave Launch at login on to start the bridge when you sign in. Close the window whenever you like; the service keeps running. Right-click the Dock icon → Options → Keep in Dock for easy access.

The bridge does not keep your Mac awake, run before login, or launch Codex/Tailscale for you.

WHEN SOMETHING NEEDS ATTENTION

Start with the status message.

Waiting for the Mac app

Open the reviewed Mac app and wait for startup to finish. If its version changed, check the compatibility record. G2 Bridge will not silently switch to a separate engine.

Waiting for the network, or the phone cannot connect

For Tailscale, check that both devices are connected to the same private network and that access rules allow TCP port 3456 on the Mac. Confirm the phone is paired to this host. For other modes, the app reports configuration rather than independent reachability validation.

A question or control needs the Mac

Supported questions and correlated approval choices can be answered from the glasses. Complex forms, sign-in, verification, file previews, and controls without a verified response route must be completed in the Mac app.

Delivery needs confirmation

Inspect the Mac conversation before sending again. The bridge keeps delivery records and avoids automatically resending an instruction whose acknowledgement was lost.

Installation or compatibility needs attention

Open Maintenance → Check Installation. Use the suggested action and check your Mac app version. In an issue report, include component versions and the safe diagnostic summary, never tokens, pairing QR codes, raw logs, or private conversation content.

Report a reproducible issue on GitHub · Read the full usage guide

A CLOSER LOOK

How it works underneath.

The Even phone app connects to an authenticated HTTP service on your Mac. G2 Bridge adapts those requests to the Mac app's private local protocol. Public responses return through Even Terminal's event stream.

The Mac app owns the task engine. The bridge stores delivery records to correlate replies and recover uncertain connections. The separate control window manages status and preferences; it is not required to stay open.
